# Ecosysteempagina's — prototypes

Klikbare prototypes voor het concept "ecosysteempagina" van FindNFund.
Deels fictieve data; bedoeld om richting te kiezen, niet om te lanceren.

- `index.html` — startpagina
- `ecosysteem-amsterdam-zoeken.html` — heel Amsterdam: 250 initiatieven en 120 funders, met filters die beide kanten op werken
- `kansengelijkheid-amsterdam-v3.html` — themapagina kansengelijkheid, gecureerd door het Nieuw Amsterdams Verbond

Alles is zelfstandig: beeld, logo's en data zitten in de bestanden.
Voor de kaart is internet nodig (OpenStreetMap).
